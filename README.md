# Disease-Spread-Prediction-using-graph-neural-networks-GNNs-
This project implements a Graph Neural Network (GNN) using a Graph Attention Network (GAT) architecture to predict the spread of COVID-19 across Indian states. Each state is modeled as a node in a graph, with edges representing geographic proximity to capture spatial dependencies. Real-time data, including confirmed case counts and mobility patterns, is used to construct node features. The model leverages attention mechanisms to learn the influence of neighboring states on infection rates. Additionally, the project integrates data visualizations and optimization tools (CVXPY, SciPy) to aid in resource planning and informed decision-making during a pandemic.
